# Rapports de recherche de la migration React

Sept rapports techniques écrits le **3 octobre 2026** avant la rédaction du [plan de migration](../PLAN.md). Ils justifient les choix du plan ; **le plan fait foi** quand il s'en écarte (les écarts sont listés au § 6.1 du plan). Les projets d'essai, clones et mesures cités dans les rapports n'ont pas été versionnés : ils sont signalés « non versionné ».
