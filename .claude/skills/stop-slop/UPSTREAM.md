## Usage dans ce dépôt

Le skill s'applique à ce que nous écrivons autour du code : commentaires, noms d'identifiants, messages de commit, descriptions de PR, README, CLAUDE.md et les documents de `docs/migration/`.

Il ne s'applique PAS aux textes affichés par l'application (`defaultMessage` react-intl, libellés, toasts) : ils sont recopiés mot pour mot de `docs/spec/`, qui fait foi.

Les documents en français gardent la typographie française (guillemets « », espaces insécables, tirets de dialogue ou d'incise). Les règles sur les tirets cadratins et les mots en « Wh- » visent l'anglais ; le reste (remplissage, voix passive, déclaratifs vagues, contrastes « pas X mais Y », formules à citation, adverbes inutiles) s'applique dans les deux langues.
